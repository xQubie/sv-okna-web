# СВ Окна — Склад, версия 45

Статическое веб-приложение для Safari и запуска с экрана «Домой». Сборка и npm не нужны.

## Оформление

Один основной стиль без выбора тем и без экрана настроек. Светлая и тёмная адаптации автоматически следуют настройке устройства, в том числе при её изменении во время работы. Прежние сохранённые настройки оформления не используются.

Обои bg_windows.jpg и bg_banya.jpg скопированы из Android-проекта Sklad; основным фоном, как и в Android, служит bg_windows.jpg. Кнопки имеют полупрозрачный материал с размытием и светлыми краями. Позиции объединены в общую панель с разделителями. На iPhone используется системный шрифт. Интерактивные элементы имеют области нажатия от 44 CSS-пикселей.

Учтены safe-area-inset-top/bottom, раздельный расчёт высоты для браузера и установленного приложения, уменьшение движения, увеличение контраста и уменьшение прозрачности в браузерах, которые поддерживают соответствующие media queries. Для браузеров без backdrop-filter предусмотрен более плотный фон. Это веб-оформление в стиле Liquid Glass; системный материал UIKit/SwiftUI в браузере не используется.

## Данные и поведение

Сохранены параметры подключения к JSONBin и прежний формат данных. Приложение только читает склад. Категории выбираются нажатием на заголовок или свайпом. Информация о категории открывается кнопкой «i». Avito копирует ссылку, Ozon открывает товар. Локальных демонстрационных данных в приложении нет.

## Установка

Разместите index.html, css/, js/, img/, fonts/, manifest.webmanifest и vercel.json на существующем HTTPS-хостинге. Параметры Vercel сохранены. В ссылках на CSS и JavaScript установлен номер 45 для обновления кэша.

На iPhone полностью закройте веб-приложение и запустите его снова после обновления сайта. Для новой установки: Safari → Поделиться → На экран «Домой».

## Проверка

В Chromium проверены загрузка реальных данных, выбор разделов, диалог информации и отсутствие горизонтального переполнения при ширинах 320, 390, 430 и 900 CSS-пикселей. При 320 px проверены области нажатия от 44 px. Тёмная адаптация проверена в отдельном временном предпросмотре с имитацией системного dark mode. Автоматический переход light → dark → light отдельно проверен через событие matchMedia. Проверены синтаксис JS, локальные ссылки на ресурсы, manifest и совпадение обоев с Android.

Физический iPhone, Safari/WebKit и системные safe-area на устройстве в этой среде не проверялись. Публикация на хостинг не выполнялась.

Ориентир по материалам: https://developer.apple.com/design/human-interface-guidelines/materials

## Исправление версии 45: нижняя полоса в iOS

В обычной вкладке используется динамическая высота viewport. При запуске с экрана «Домой» используется полная высота 100lvh (100vh как fallback), в том числе для фонового слоя. Режим определяется через display-mode: standalone и navigator.standalone для iOS.

Разница между полной высотой приложения и видимой областью измеряется при запуске, изменении размеров, повороте и возвращении на страницу. Нижний прокручиваемый отступ списка равен 24 px плюс максимум из безопасного отступа устройства и измеренной перекрытой области. Отступы не складываются дважды. Это позволяет вывести последнюю строку выше области, которую перекрывает оболочка iOS.

Проверка в Chromium: тестовый список из 40 позиций и имитация недостающей высоты 60 px. После прокрутки до конца нижняя граница последней строки находилась на 24,7 px выше доступной границы. В обычном режиме измеренная компенсация равна 0. Проверены автоматическое определение установленного режима, светлая/тёмная адаптации, синтаксис JS и ресурсы. На физическом iPhone результат пока не подтверждён.

Связанная проблема WebKit: https://bugs.webkit.org/show_bug.cgi?id=254868
