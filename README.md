# СВ Окна — склад Liquid Glass

Готовый статический проект для размещения вместо предыдущей версии. Сборка и npm не нужны.

## Установка

1. Распакуйте архив.
2. Замените файлы сайта содержимым папки `sklad-web`, включая `css` и `js`. В архиве сохранён `vercel.json`.
3. Откройте сайт по HTTPS. На iPhone: Safari → Поделиться → На экран «Домой».
4. Если установлена старая версия, полностью закройте веб-приложение и откройте заново. При необходимости обновите страницу в Safari.

## Данные

Адрес JSONBin и существующие параметры доступа сохранены в `js/app.js`. Приложение только читает данные; записей в облако нет. Товаров, цен, остатков, демонстрационных данных и резервного списка разделов в проекте нет.

Поддерживается прежняя схема JSON:

- `_categories` — массив ключей разделов в нужном порядке. Если его нет, разделы строятся из полей JSON, содержащих массивы.
- `_category_titles` — отображаемые названия разделов по их ключам.
- `_category_infos` — пояснения к разделам по их ключам.
- Каждый раздел — массив позиций с полями `name`, `quantity`, `price`, `avito`, `ozon`, `showQuantity`.

Дополнительные массивы из JSON также становятся разделами. Поддерживается прямой JSON и ответ в оболочке `record`. Сохранена совместимость с прежними ключами разделов со скидками. Специальные правила «Условия доставки» (текст без цен) и «Двери ПВХ» (количество по умолчанию) сохранены; сами эти разделы локально не создаются. Скидка в названии показывается отдельной меткой и повторно к цене не применяется.

Данные загружаются при открытии и по кнопке обновления. При неудачном обновлении ранее загруженные данные остаются на экране, но выводится сообщение об ошибке. При первом открытии без связи вымышленные остатки не показываются.

## Версия 43

- Кнопка «i» открывает обычный диалог по центру. Открытие: плавное увеличение и появление за 280 мс; закрытие: затухание за 180 мс.
- После успешной загрузки JSON видимые строки появляются последовательно: шаг 95 мс, длительность 340 мс. Строки за пределами экрана доступны сразу при прокрутке.
- Каждый шаг сопровождается запросом мягкого тактильного отклика в Telegram Mini App через HapticFeedback. В обычном браузере используется navigator.vibrate(8), только если API доступен и уже было взаимодействие с пользователем. Автоматическая вибрация при первом открытии не гарантируется браузером.
- При уходе в фон, смене раздела или открытии информации незавершённая последовательность отменяется. При возвращении после 15 секунд в фоне данные обновляются и анимация повторяется.
- «Уменьшение движения» отключает последовательное появление и сопровождающие импульсы.
- Версии CSS и JS обновлены до 43.

## Основа версии 42

- Нижняя информационная панель полностью удалена.
- Информация о разделе открывается кнопкой «i» справа напротив заголовка.
- Фиксированные размеры элементов, отступов, иконок и шрифтов уменьшены на 10%. Размер рабочей области и безопасные отступы устройства сохранены.
- Разделы переключаются свайпами. Нажатие на название раздела открывает список для прямого выбора.
- Три стеклянных оформления, светлая/тёмная/системная схемы, выдвижные настройки и сохранение предпочтений работают как раньше.
- Avito копирует ссылку, Ozon открывает товар. Данные только из облачного JSON, локально сохраняются лишь настройки оформления.
- В версии 42 были обновлены размеры интерфейса. Замените файлы сайта, полностью закройте веб-приложение и откройте снова.

## Проверка

Для версии 43 проверены реальные задержки анимации, расположение диалога по центру, его открытие/закрытие и режим уменьшения движения. Вызовы Telegram HapticFeedback проверены на имитации API; физический отклик на устройстве не проверялся.

В Chromium проверены отсутствие нижней панели, уменьшение размеров шрифтов на 10%, положение кнопки «i», окно информации, выбор раздела, свайпы, настройки и сохранение схемы. Проверены ширины 320, 402 и 900 CSS-пикселей. На физическом iPhone проверка не выполнялась.

В папке `previews` — снимки интерфейса с тестовыми данными, не используемыми приложением. Параметры подключения к облачному JSON сохранены. Из среды подготовки действующий JSONBin ранее отвечал HTTP 403; проверка интерфейса выполнена на тестовом ответе прежнего формата.
