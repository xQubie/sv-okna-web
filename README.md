# СВ Окна — склад и калькулятор окон

Готовые файлы для существующего репозитория GitHub и размещения на Vercel. Сборка, npm install и отдельная база данных не требуются.

## Как загрузить

1. Откройте свой репозиторий GitHub.
2. Выберите **Add file → Upload files**.
3. Перетащите **содержимое этой папки**: файлы и папки `api`, `css`, `img`, `js`. Не загружайте ZIP вместо файлов и не создавайте лишнюю внешнюю папку.
4. Сохраните загрузку кнопкой **Commit changes**.

`index.html`, `calculator.html` и `vercel.json` должны находиться в корне репозитория. При подключении репозитория к Vercel укажите этот корень; содержимое папок нужно сохранить полностью.

## Подключение склада

Предоставленный Access Key уже добавлен в серверный обработчик `api/warehouse.js`. Браузер получает склад через этот обработчик. Master Key в комплект не включён. Для запуска на Vercel дополнительные переменные окружения не обязательны.

Если понадобится заменить ключ без правки файлов, добавьте в настройках Vercel переменную **`JSONBIN_ACCESS_KEY`** с новым значением и выполните новое развёртывание. Переменная имеет приоритет над добавленным ключом. Для чтения достаточно разрешения **Bins → Read**; Create, Update и Delete приложению не нужны.

Файл `.env.example` содержит необязательный пример настройки с пустым значением. Идентификатор облачного склада уже указан в серверном обработчике. Не добавляйте в репозиторий Master Key и личные `.env`-файлы.

Документация: [чтение JSONBin](https://jsonbin.io/api-reference/bins/read), [переменные окружения Vercel](https://vercel.com/docs/environment-variables).

## Что работает

- Склад с обновлением данных, разделами и прежним оформлением.
- Кнопка калькулятора в верхней панели рядом с обновлением и переходом на сайт.
- Расчёт окон, комплектация, заказ, история и настройки организации.
- Номер КП, логотип, мессенджеры, размеры на чертежах и выбранные характеристики.
- Предпросмотр и скачивание PNG по высоте содержимого.
- Проверка актуальности цен через `api/calculator-prices.js` с сохранением последнего совместимого прайса.
- Автоматическая светлая/тёмная схема устройства.

Заказы и реквизиты сохраняются в текущем браузере. Между устройствами они автоматически не синхронизируются. Сохранённые позиции меняют цену только после явного пересчёта.

## Размещение

Комплект рассчитан на **Vercel**: серверные функции лежат в `api/`. GitHub хранит исходники; GitHub Pages не выполняет эти функции. Без серверных функций приватный облачный склад и проверка цен недоступны.

В папке уже есть все необходимые изображения и скрипты. Библиотека html2canvas 1.4.1 включена локально с MIT-лицензией в `js/calculator/vendor/`; внешний CDN для сохранения PNG не нужен.

## Проверка

В Chromium проверены мобильные и широкие раскладки, обе схемы оформления, расчёт, сохранение истории и фактическое скачивание PNG. Физические iPhone/Safari и Telegram Mini App требуют отдельной проверки на устройстве.

Служебная папка `.git`, резервные копии склада, тестовые данные и личные настройки в комплект не включены. Загрузка в GitHub и публикация выполняются владельцем репозитория.
