# СВ Окна — склад Liquid Glass

Готовый статический проект для размещения вместо предыдущей версии. Сборка и npm не нужны.

## Установка

1. Распакуйте архив.
2. Замените файлы сайта содержимым папки `sklad-web`, включая `css` и `js`. В архиве сохранён `vercel.json`.
3. Откройте сайт по HTTPS. На iPhone: Safari → Поделиться → На экран «Домой».
4. Если установлена старая версия, полностью закройте веб-приложение и откройте заново. При необходимости обновите страницу в Safari.

## Данные

Адрес JSONBin и существующие параметры доступа сохранены в `js/app.js`. Приложение только читает данные; записей в облако нет. Товаров, цен, остатков, демонстрационных данных и резервного списка разделов в проекте нет.

Поддерживается прежняя схема JSON:

- `_categories` — массив ключей разделов в нужном порядке. Если его нет, разделы строятся из полей JSON, содержащих массивы.
- `_category_titles` — отображаемые названия разделов по их ключам.
- `_category_infos` — пояснения к разделам по их ключам.
- Каждый раздел — массив позиций с полями `name`, `quantity`, `price`, `avito`, `ozon`, `showQuantity`.

Дополнительные массивы из JSON также становятся разделами. Поддерживается прямой JSON и ответ в оболочке `record`. Сохранена совместимость с прежними ключами разделов со скидками. Специальные правила «Условия доставки» (текст без цен) и «Двери ПВХ» (количество по умолчанию) сохранены; сами эти разделы локально не создаются. Скидка в названии показывается отдельной меткой и повторно к цене не применяется.

Данные загружаются при открытии и по кнопке обновления. При неудачном обновлении ранее загруженные данные остаются на экране, но выводится сообщение об ошибке. При первом открытии без связи вымышленные остатки не показываются.

## Интерфейс Liquid Glass

- Три оформления: тёплое, синее, серебристое. У каждого есть светлая и тёмная цветовая схема.
- Системная схема следует настройке устройства и обновляется при её изменении.
- Шестерёнка вверху открывает настройки снизу примерно на 2/3 экрана; на низких экранах панель выше, содержимое прокручивается.
- Настройки применяются сразу и запоминаются на этом устройстве. Серебристое оформление и системная схема выбраны по умолчанию.
- Настройки закрываются крестиком, касанием снаружи, Escape или свайпом вниз за верхнюю ручку.
- Размер/название позиции слева, цена справа, наличие и ссылки под ними.
- Карточки разделов с описанием расположены внизу. Их горизонтальное перелистывание переключает основной список товаров. Свайп основного списка также переключает нижнюю карточку. Можно нажать на карточку или открыть список «Все разделы».
- Полное описание раздела доступно по кнопке «i». Длинные описания в нижней карточке сокращаются по высоте.
- Avito копирует ссылку, Ozon открывает страницу. Кнопка глобуса открывает прежний сайт.
- Сохранена интеграция Telegram Web App.
- Учтены safe area, нижний индикатор iPhone, уменьшение движения и узкие экраны.
- Стекло реализовано средствами CSS: размытие фона, прозрачность, световые грани, тени. Это веб-оформление по макетам, а не системный материал Apple.

## Проверка

Проверены все шесть сочетаний оформления, системная схема, сохранение настроек после перезагрузки и синхронизация нижних карточек с основным экраном. Дополнительно проверены в Chromium: светлая и тёмная темы, меню разделов, количество товаров, доставка без цен, окно информации, копирование ссылок, ошибка обновления, повторная загрузка и появление нового раздела из JSON. Проверены ширины от 320 до 900 CSS-пикселей. На физическом iPhone Safari проверка не выполнялась.

В папке `previews` рядом с сайтом — снимки интерфейса с тестовыми данными только для просмотра дизайна. Эти изображения не используются приложением.

Сетевое подключение к действующему JSONBin из среды подготовки получило HTTP 403. Адрес и параметры запроса сохранены; живые цены и остатки здесь не подтверждались. Перед использованием откройте размещённый сайт на iPhone и проверьте загрузку своего JSON.
